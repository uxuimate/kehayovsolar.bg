Battery energy storage systems (BESS)

A battery for a new or existing system — so you can use the energy you produce when there is no sun.

Request a quote
what it is

What is a storage system?

BESS stores generated electricity so you can use it when there is no sun or when consumption requires it. Without a battery a grid-tied system uses energy as it is produced; with a battery part of it remains for the evening and darker hours.

Storage is not required for every installation. We add it when the site’s operating pattern justifies it. We use Deye battery systems.

suitable for

Who this system is for

Battery storage is not required for every installation. We add it when consumption, operating pattern and goals justify it. We use Deye battery systems.

  • New hybrid systems with a planned battery
  • Sites that want to use more of their own generation
  • Clients with consumption outside sunny hours
  • Sites where backup during an outage matters

when

When a battery makes sense

The decision is by site, not catalogue. We most often discuss it when:

  • There is consumption outside sunny hours
  • You want to use more of your own generation
  • Backup during an outage matters for the site
  • You are planning a hybrid system now or later

Capacity is chosen from the load and how the system is connected. No ready-made kWh figures on the website.

integration

On a new or an existing system

A battery can be part of a new hybrid installation or discussed for an already built site when compatibility and goals allow it.

On a new system we plan the inverter and storage together. On an existing one we first check what is on site and whether adding BESS makes sense. The specific case is confirmed after a site visit.

Questions

Frequently asked questions

What is BESS?

An energy storage system. It stores the electricity produced so you can use it when there is no sun or when consumption requires it.

Is a battery required?

No. We add it when consumption, operating pattern and goals justify it. We use Deye battery systems.

Can it be added to a new and an existing system?

Yes — on a new hybrid system with a planned battery, or when it makes sense on an already built site. The specific case is confirmed after a site visit.

How much does storage cost?

It depends on capacity and how it connects to the site. The quote follows an enquiry — no ready-made prices on the site.
